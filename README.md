# School Reminder · Sitio web + panel administrativo

Primera base visual del ecosistema de School Reminder.

## Sitio
- `index.html`: página principal.
- `soporte.html`: formulario de dudas, sugerencias y errores.
- `assets/logo.png`: logo proporcionado.
- `assets/tutorial.mp4`: coloca aquí el video tutorial cuando lo tengas.

## Panel
- `admin/index.html`: dashboard administrativo visual.
- `js/admin.js`: datos de demostración y navegación.
- `css/admin.css`: diseño del panel.

## Próxima etapa
Conectar la app Android y este sitio con Firebase:
- Firebase Authentication para Google/correo.
- Firestore para tickets, sugerencias, errores y perfiles.
- Roles de administrador mediante Custom Claims.
- Backend seguro para acciones administrativas.
- Notificación privada al administrador sin mostrar su correo al usuario.
